###Extrinsic Interocular Transform Finder

Takes positional data from intrinsic calibrator and converts it into transforms between camera components. Can also perform rectification operations (WIP).

Run with `roslaunch iod_calc interocular.launch`.

Initial position data is generated by the intrinsic_calibrator package, and assumes that all of the cameras are in a fixed position w.r.t. the origin of the calibration sled.
